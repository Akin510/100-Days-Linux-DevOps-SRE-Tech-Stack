# 📖 Introduction

One of the first skills every Linux System Administrator must learn is **file and directory management**.

Linux provides several command-line utilities for managing files and directories.

Some of the most commonly used commands are:

- `mkdir` – Create directories
- `cd` – Change directories
- `pwd` – Display the current working directory
- `ls` – List directory contents

In this lab, we will focus on creating directories using the **mkdir** command.

---

# What is `mkdir`?

The `mkdir` command stands for:

> **Make Directory**

It is used to create:

- A single directory
- Multiple directories
- Parent directories
- Nested subdirectories

---

# Basic Syntax

```bash
mkdir directory_name
```

Example:

```bash
mkdir test
```

This creates a directory named **test** inside the current working directory.

# 🔬 Lab 7 – Attempt to Create an Existing Directory

Suppose the directory already exists.

Command:

```bash
mkdir projectX
```

Expected Output:

```text
mkdir: cannot create directory 'projectX': File exists
```

Linux prevents creating duplicate directories and displays an error message.

---

# Understanding the Error

If the directory already exists:

- The directory is not recreated.
- Existing data is not modified.
- Linux simply displays an error.

# 🔬 Lab 8 – Create Parent and Nested Directories

Sometimes you need to create several levels of directories at once.

For this purpose, use the `-p` option.

Syntax:

```bash
mkdir -p parent/subdirectory/subdirectory
```

Example:

```bash
mkdir -p project/app/guacamole
```

This command creates:

```text
project
└── app
    └── guacamole
```

Even if the parent directory does not already exist, Linux creates every required directory automatically.
