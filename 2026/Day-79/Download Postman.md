# Postman Installation and Initial Setup
> **Installing Postman and Preparing Your Workspace**

---

# 🎯 Learning Objectives

By the end of this lesson, you will be able to:

- Understand what Postman is.
- Understand the available ways to use Postman.
- Create a Postman account.
- Use Postman in a web browser.
- Download and install the standalone Postman application.
- Sign in to the Postman desktop application.
- Open your personal workspace.
- Understand that the Postman interface may change slightly over time.
- Change the Postman interface to Dark Theme.

---

# 📖 Introduction

In this lesson, we will learn how to install **Postman**.

Postman uses a **freemium pricing model**.

For many use cases, including the requirements of this training course, Postman can be used for free.

There are two main ways to run Postman:

1. In your web browser.
2. As a standalone application installed on your computer.

---

# Ways to Use Postman

Postman can be used in two main ways:

| Method | Description |
|---|---|
| Postman on the Web | Runs directly inside your browser |
| Postman Desktop Application | Installed as a standalone application on your computer |

---

# Postman on the Web

The browser-based version is called:

```text
Postman on the Web
```

You can access Postman from your browser without installing the full desktop application.

This is useful if you:

- Do not want to install software.
- Are working on a temporary computer.
- Prefer browser-based tools.

---

# Postman Desktop Application

Alternatively, you can download and install the standalone Postman application.

The desktop application is available for several operating systems, including:

- Windows
- macOS
- Linux

The instructor in this lesson will use the **standalone Postman application**.

However, the functionality of the browser version is very similar.

---

# ⚠️ Do Not Use the Old Chrome Extension

There was previously an old Postman extension for Google Chrome.

That extension is now:

```text
Deprecated
```

Do not use the old Chrome extension.

If you use it, you may not be able to follow the course correctly.

Use either:

```text
Postman on the Web
```

or:

```text
Postman Desktop Application
```

# Step 1 – Go to the Postman Website

The first step is to visit the Postman website.

Open your preferred web browser.

Examples:

- Google Chrome
- Microsoft Edge
- Firefox
- Safari

Then go to:

```text
postman.com
```

---

# Step 2 – Create a Postman Account

Create a Postman account.

Although Postman may provide different ways of using the service, creating an account is strongly recommended.

Having an account makes the setup and future use easier.

It can also help you keep your work organized.

---

# Why Create a Postman Account?

A Postman account makes it easier to:

- Access your workspace.
- Keep your work organized.
- Use Postman from different devices.
- Connect the desktop application to your account.
- Continue your work later.

---

# Step 3 – Complete the Initial Setup

After creating your account, Postman may ask you to provide some additional information.

Complete the required fields.

The exact questions may vary depending on the current Postman version.

At this stage, you do not need to create a team for this course.

If Postman asks whether you want to create a team, you can skip that step.

---

# Step 4 – Open Workspaces

To begin using Postman, navigate to:

```text
Workspaces
```

Then select:

```text
My Workspace
```

This will be the main area where we organize our work throughout the course.

---

# What Is a Workspace?

A **Workspace** is an area where Postman organizes your API-related work.

We will use the workspace to organize things such as:

- Requests
- Collections
- API tests
- Environments
- Variables

For now, simply open:

```text
My Workspace
```

---

# Using Postman in the Browser

If you want to use the browser version of Postman, once you have opened:

```text
Workspaces
```

and selected:

```text
My Workspace
```

you are essentially ready to begin.

You do not need to install the standalone application.

---

# Installing the Postman Desktop Application

If you want to use the standalone Postman application, the next step is to download and install it.

Postman provides installers for:

- Windows
- macOS
- Linux

Choose the installer that matches your operating system.

---

# Step 5 – Download Postman

From the Postman website, locate the download section.

Select the correct installer for your operating system.

Examples:

```text
Windows
macOS
Linux
```

Download the installer.

---

# Step 6 – Install Postman

Once the download has completed, locate the installer on your computer.

On Windows, it will usually be inside:

```text
Downloads
```

Open the installer and follow the installation prompts.

The installation process is generally straightforward.

---

# Step 7 – Launch Postman

After installation, open the Postman desktop application.

When Postman opens for the first time, the interface should look similar to the web version.

The exact layout may vary depending on the current release.

---

# Step 8 – Sign In to the Desktop Application

To connect the desktop application to your Postman account, click:

```text
Sign In
```

Use the same account you created earlier.

Once signed in, your desktop application will be linked to your Postman account.

---

# Step 9 – Open My Workspace

After signing in, navigate to:

```text
Workspaces
```

Then select:

```text
My Workspace
```

This is the primary area where we will organize our work.

---

# Postman Interface Changes

Postman is actively developed.

This means the interface may change over time.

By the time you take this course, you may notice small differences between:

- The interface shown in the lesson.
- The interface currently available on your computer.

This is normal.

The exact location of buttons or menus may change slightly, but the core concepts remain the same.

---

# Important Note About Versions

Do not worry if your screen does not look exactly like the lesson.

Postman may release:

- New versions
- Interface changes
- Menu changes
- Additional features

The important concepts and workflows generally remain the same.

Course notes or videos can be updated if a major change affects the learning process.

---

# Step 10 – Change to Dark Theme

One useful interface preference is the **Dark Theme**.

To change the theme, open:

```text
Settings
```

Then locate:

```text
Themes
```

Select:

```text
Dark
```

---

# Theme Configuration Flow

```text
Postman
   │
   ▼
Settings
   │
   ▼
Themes
   │
   ▼
Dark Theme
```

---

# Why Use Dark Theme?

Dark Theme is optional.

Some users prefer it because:

- It can be easier on the eyes.
- It may be more comfortable during long sessions.
- It can make code and API requests easier to read.

You may use whichever theme you prefer.
