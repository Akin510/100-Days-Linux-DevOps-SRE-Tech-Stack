# 1. Certification Overview

The Dell Technologies PowerEdge Foundations v2 certification validates fundamental knowledge of enterprise server technologies, Dell PowerEdge hardware architecture, server roles, management, networking, maintenance, and security.

Candidates should understand:

- Enterprise server fundamentals
- Dell PowerEdge hardware components
- CPU and memory architecture
- Server storage technologies
- Dell PERC RAID controllers
- Server deployment models
- Virtualization technologies
- Dell iDRAC management
- Dell OpenManage tools
- Server networking
- Hardware troubleshooting
- Firmware and driver maintenance
- Power and cooling infrastructure
- Enterprise server security

# 10. NIT Academy Final Practical Assessment

The following assessment is an NIT Academy teaching recommendation, not part of Dell's certification examination.

## Assessment Tasks

1. Identify a Dell PowerEdge server and its major hardware components.
2. Identify installed processors and memory.
3. Explain RAID 0, 1, 5, 6, and 10.
4. Explain the role of a Dell PERC controller.
5. Compare SAS, SATA, and NVMe storage.
6. Explain DAS, NAS, and SAN.
7. Explain the differences between bare-metal servers and virtual machines.
8. Configure an IP address on a Rocky Linux server.
9. Access a compatible Dell iDRAC controller.
10. Identify hardware health alerts.
11. Explain firmware update procedures.
12. Diagnose a simulated disk failure.
13. Explain redundant server power supplies.
14. Describe server cooling methods.
15. Explain Secure Boot and TPM 2.0.
16. Explain Silicon Root of Trust.
17. Demonstrate basic Linux hardware diagnostic commands.
18. Produce a server onboarding and hardware inspection checklist.

Upon completing this syllabus, students should be able to:

- Explain Dell PowerEdge server architecture.
- Identify enterprise server hardware components.
- Explain server storage and RAID configurations.
- Understand physical and virtual server deployment models.
- Describe Dell iDRAC and OpenManage management functions.
- Recognize hardware health and maintenance requirements.
- Explain basic enterprise server connectivity.
- Identify major Dell server security technologies.
- Perform foundational Linux server inspection tasks.
- Prepare for the Dell Technologies D-PE-FN-01 certification examination.
