# What Is Apache?

Apache is a piece of application software.

In simple terms:

> **Apache is a web server application.**

It is widely used for hosting websites and web applications.

Apache is commonly used on Unix-like operating systems, but it can also run on other platforms such as Windows.

---

# Apache as a Web Server

If you want to host a website on a Linux or Unix-based operating system, you need web server software.

One commonly used application is:

```text
Apache HTTP Server
```

The basic environment looks like this:

```text
Linux Server
     │
     ▼
Apache Web Server
     │
     ▼
Website Files
```

Apache manages the website and responds to requests from users.

---

# What Is a Web Server?

A web server is responsible for:

- Accepting HTTP requests from clients.
- Processing those requests.
- Returning HTTP responses.
- Serving website content.

Website content may include:

- Static text.
- Images.
- HTML pages.
- Scripts.
- Dynamic content.

---

# Basic Web Server Communication

```text
Web Client
    │
    │ HTTP Request
    ▼
Apache Web Server
    │
    │ HTTP Response
    ▼
Web Client
```

The client may be:

- A web browser.
- A mobile application.
- Another software application.

Apache receives requests and sends responses back to the clients.

# HTTP Communication

Traditional HTTP communication uses:

```text
HTTP
```

The default HTTP port is:

```text
80
```

Communication looks like:

```text
Client
   │
   │ HTTP
   │ Port 80
   ▼
Apache Server
```

---

# Why Plain HTTP Is Less Secure

With traditional HTTP, communication is not protected by HTTPS encryption.

Sensitive traffic may be easier for an attacker who can observe the network to inspect.

Therefore, administrators usually prefer secure encrypted communication.

---

# HTTPS

HTTPS stands for:

```text
Hypertext Transfer Protocol Secure
```

The default HTTPS port is:

```text
443
```

The communication becomes:

```text
Client
   │
   │ HTTPS
   │ Port 443
   │ Encrypted
   ▼
Apache Server
```

---

# HTTP vs HTTPS

| Feature | HTTP | HTTPS |
|---|---|---|
| Default Port | 80 | 443 |
| Encryption | No HTTPS encryption | Yes |
| Recommended for Sensitive Data | No | Yes |
| Security | Lower | Higher |
| Common Modern Use | Redirect or limited use | Preferred |

---

# TLS and SSL

HTTPS uses cryptographic protocols to secure communication.

Modern HTTPS uses:

```text
TLS
```

TLS stands for:

```text
Transport Layer Security
```

You may also hear the older term:

```text
SSL
```

SSL stands for:

```text
Secure Sockets Layer
```

In modern systems, TLS is the protocol generally used for secure HTTPS communication.

---

# Secure Communication Flow

```text
Client
   │
   │ HTTPS Request
   │ Encrypted with TLS
   ▼
Apache Web Server
   │
   │ HTTPS Response
   │ Encrypted with TLS
   ▼
Client
```

---

# Why HTTPS Is Preferred

HTTPS helps protect:

- Login credentials.
- Session information.
- Personal information.
- Financial data.
- API requests.
- Website traffic.

For public websites, encrypted communication should normally be used whenever possible.

# What Are Virtual Hosts?

A virtual host allows one Apache server to host multiple websites.

Example:

```text
Apache Server
      │
      ├── www.company1.com
      │
      ├── www.company2.com
      │
      └── www.company3.com
```

Each website can have its own:

- Document root.
- Configuration.
- Logs.
- Domain name.
- Security settings.

Virtual hosts will be covered in more detail later.

>      ▼
> Apache Web Server
>      │
>      ▼

>
> ```text
> Website Content

>      ▼
> Apache Web Server
>      │
>      │ HTTP/HTTPS Response
>      ▼
> Web Browser
> ```
