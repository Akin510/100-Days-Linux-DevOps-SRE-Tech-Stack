# 📖 Introduction

In this lesson, we will learn how to declare and use **constant variables** in Bash.

The words:

```text
Constant
```

and:

```text
Variable
```

may sound contradictory.

A **variable** normally suggests something that can change.

A **constant** means something that stays the same.

In Bash, a constant variable is simply a variable whose value is protected from being changed after it has been declared as read-only.

---

# What Is a Constant Variable?

A constant variable is a variable whose value does not change.

For example, consider the mathematical constant:

```text
PI
```

A commonly used approximation is:

```text
3.14159
```

The value of PI is treated as constant.

In Bash, we can protect a variable so that it cannot be reassigned.

---

# Normal Variable vs Constant Variable

## Normal Variable

A normal variable can be changed.

Example:

```bash
color="Blue"
```

Display it:

```bash
echo "$color"
```

Output:

```text
Blue
```

Now change it:

```bash
color="Red"
```

Display it again:

```bash
echo "$color"
```

Output:

```text
Red
```

The value changed successfully.

---

## Constant Variable

A constant variable is protected from reassignment.

Example:

```bash
readonly PI=3.14159
```

Display it:

```bash
echo "$PI"
```

Output:

```text
3.14159
```

Now attempt to change it:

```bash
PI=10
```

Bash will display an error similar to:

```text
bash: PI: readonly variable
```

---

# The `readonly` Command

Bash uses the:

```bash
readonly
```

command to create a constant variable.

General syntax:

```bash
readonly VARIABLE_NAME=value
```

Example:

```bash
readonly PI=3.14159
```

---

# How `readonly` Works

```text
Create Variable
      │
      ▼
readonly PI=3.14159
      │
      ▼
PI Becomes Read-Only
      │
      ▼
Try to Change PI
      │
      ▼
Bash Rejects the Change
```

# Why Does Bash Reject the Change?

When you run:

```bash
readonly PI=3.14159
```

Bash marks `PI` as read-only.

After that, this is not allowed:

```bash
PI=10
```

The value cannot be reassigned in the same shell or script execution.

# Constant Naming Convention

Constants are commonly written using uppercase letters.

Examples:

```bash
readonly PI=3.14159
```

```bash
readonly TAX_RATE=8
```

```bash
readonly MAX_USERS=100
```

```bash
readonly BACKUP_DIR="/backup"
```

Using uppercase letters is not mandatory, but it makes constants easier to identify.

---

# Where Are Constants Useful?

Constants are useful when a value should remain fixed during script execution.

Examples include:

- Mathematical constants
- Scientific values
- Tax rates
- Interest rates
- Application versions
- Fixed directory paths
- Maximum limits
- Company names
- Configuration values

---

# Example – Fixed Directory

```bash
readonly BACKUP_DIR="/backup"
```

Display:

```bash
echo "Backup directory: $BACKUP_DIR"
```

The script can use this path many times without allowing accidental reassignment.

# Example – Tax Rate


Example:


# LAB 7 – Tax Calculation Script

Create:

```bash

```

```bash

```

Make it executable:

```bash
chmod u+x tax.sh
```

Run:

```bash
./tax.sh
```

Expected output:

```text
Gross Salary: 5000
Tax Rate: 10%
Tax Amount: 500
Net Salary: 4500
```

# Alternative Syntax – `declare -r`

Bash also allows you to create a read-only variable using:

```bash
declare -r PI=3.14159
```

Display it:

```bash
echo "$PI"
```

Attempt to modify it:

```bash
PI=10
```

Bash will reject the change.

---

# `readonly` vs `declare -r`

| Syntax | Purpose |
|---|---|
| `readonly PI=3.14159` | Create a read-only variable |
| `declare -r PI=3.14159` | Create a read-only Bash variable |

For beginner Bash scripting, `readonly` is usually easier to understand.

# 🔧 Troubleshooting

## Problem 1 – `readonly` Command Written Incorrectly

Incorrect:

```bash
read only PI=3.14159
```

Correct:

```bash
readonly PI=3.14159
```

`readonly` is one word.

---

## Problem 2 – Spaces Around `=`

Incorrect:

```bash
readonly PI = 3.14159
```

Correct:

```bash
readonly PI=3.14159
```

Bash variable assignments must not contain spaces around `=`.

---

## Problem 3 – Variable Name Displays Instead of Value

Incorrect:

```bash
echo PI
```

Output:

```text
PI
```

Correct:

```bash
echo "$PI"
```

Output:

```text
3.14159
```

---

## Problem 4 – Constant Can Be Changed in a New Terminal

A read-only variable applies to the shell or script where it was declared.

For example:

```bash
readonly PI=3.14159
```

protects `PI` in that shell.

If you open another terminal, a new shell is created and that variable may not exist there.

---

## Problem 5 – Script Produces a `readonly variable` Error

Check whether the script contains a reassignment like:

```bash
PI=10
```

after:

```bash
readonly PI=3.14159
```

Remove or comment out the reassignment:

```bash
# PI=10
```

# 📖 Key Takeaways

- A constant variable is a variable whose value is protected from change.
- Bash uses the `readonly` command to create constants.
- A normal variable can be made read-only later.
- Once a variable is read-only, Bash will reject reassignment.
- Constants are useful for values that should remain fixed during script execution.
- Uppercase names are commonly used for constants.
- `declare -r` is another way to create a read-only variable.
- Constants are useful for mathematical values, configuration settings, limits, paths, rates, and versions.
